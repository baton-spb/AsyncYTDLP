# Модель отмены операций и таймауты в async-yt-dlp

В асинхронных приложениях корректная обработка отмены задач (`asyncio.CancelledError`)
и таймаутов имеет фундаментальное значение.

В этом документе честно и подробно раскрыты особенности отмены операций при интеграции
асинхронного event loop с синхронным ядром `yt-dlp`.

---

## 1. Честное объяснение модели отмены

> [!IMPORTANT]
> CPython не предоставляет механизма безопасного принудительного уничтожения работающего системного потока (OS thread) извне. 

Когда вы вызываете `task.cancel()` для задачи, выполняющей скачивание через `async-yt-dlp`:
1. **Корутина немедленно прерывается**: в месте вызова `await ytdlp.download(...)` незамедлительно возбуждается `asyncio.CancelledError`.
2. **Event Loop освобождается**: ваше приложение мгновенно продолжает работу или отвечает пользователю.
3. **Поведение фонового потока**:
   - Если задача **ожидала в очереди семафора**: она отменяется мгновенно, не занимая рабочий поток.
   - Если поток **уже скачивает данные**: `yt-dlp` продолжит загрузку текущего фрагмента/файла до естественного завершения, после чего поток завершится, а результат будет отброшен.

---

## 2. Использование таймаутов (`asyncio.timeout`)

Рекомендуемый в Python 3.14+ способ установки дедлайна на операцию — использование контекстного менеджера `asyncio.timeout`:

```python
import asyncio
from async_yt_dlp import AsyncYTDLP


async def download_with_timeout(url: str):
    async with AsyncYTDLP() as ytdlp:
        try:
            # Устанавливаем жесткий лимит времени: 120 секунд
            async with asyncio.timeout(120.0):
                result = await ytdlp.download(url)
                print(f"Успешно скачано: {result.filepath}")
        except TimeoutError:
            print("Скачивание превысило допустимый лимит времени (120 сек) и было отменено!")
```

## 3. Отмена стрима прогресса (`download_with_progress`)

При использовании асинхронного генератора `download_with_progress` прерывание цикла `break`
автоматически вызывает финализацию генератора и отмену фоновой задачи:

```python
async with AsyncYTDLP() as ytdlp:
    stream = ytdlp.download_with_progress(url)
    
    async for event in stream:
        print(f"Прогресс: {event.percent}%")
        if user_clicked_cancel_button():
            print("Пользователь нажал отмену!")
            break  # Выход из цикла автоматически отменяет фоновую задачу загрузки
```

## 4. Корректное завершение работы (Graceful Shutdown)

При выходе из контекстного менеджера `async with AsyncYTDLP()` или явном вызове `await ytdlp.close()`:
1. Клиент перестает принимать новые запросы (`LifecycleError`).
2. Ожидает завершения текущих активных задач до истечения таймаута (`timeout=15.0`).
3. Принудительно отменяет зависшие задачи, если они превысили лимит ожидания shutdown.

```python
ytdlp = AsyncYTDLP()
# ... работаем ...
# Завершаем работу с ожиданием активных задач до 10 секунд:
await ytdlp.close(wait=True, timeout=10.0)
```
