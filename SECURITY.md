# Политика безопасности (Security Policy)

Безопасность пользователей и защита конфиденциальных данных являются ключевыми приоритетами проекта `async-yt-dlp`.

---

## 1. Поддерживаемые версии

В настоящее время активные исправления безопасности выпускаются для следующих версий:

| Версия | Поддержка безопасности |
| :--- | :--- |
| `0.1.x` |  Поддерживается |

---

## 2. Сообщение об уязвимостях

Если вы обнаружили потенциальную уязвимость безопасности в библиотеке:

1. **Не создавайте публичный Issue в трекере задач.**
2. Отправьте конфиденциальное сообщение мейнтейнерам проекта с описанием проблемы и шагами воспроизведения (Proof of Concept).
3. Команда ответит на ваш запрос в течение 48 часов и согласует сроки устранения уязвимости до публичного раскрытия.

---

## 3. Базовые принципы безопасности библиотеки

- **Изоляция URL-схем**: доступ к протоколу `file://` по умолчанию заблокирован для предотвращения SSRF.
- **Санитизация секретов**: токены, пароли учетных записей и параметры прокси автоматически маскируются при логировании.
- **Изоляция сессий**: для каждого запроса создается независимый экземпляр `YoutubeDL`, что исключает утечку cookies между параллельными задачами.
